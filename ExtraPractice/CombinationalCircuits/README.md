# Extra practice - combinational circuits

[All topics](../../README.md)

This collection keeps the student's separate Assignment 1 working code: a half subtractor, a full subtractor using half subtractors, gate-level 2-to-1 and hierarchical 4-to-1 multiplexers, and a 2-to-4 dataflow decoder. Its original numbering stays separate from the six course topics.

The editable RTL and matching TBs are copied unchanged. Saved waveform images and Quartus RTL schematics are included beside the relevant code on its design page. The original assignment PDF/question sheet is not included.
