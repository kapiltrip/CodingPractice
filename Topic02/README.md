# Topic 2 - Operators

[All topics](../README.md) · [Import and evidence notes](../maintenance/IMPORT.md)

## What this topic practises

Practise Verilog operators through an ALU with two 8-bit inputs, a 16-bit output, sixteen operations, and output-enable control. The course introduces task arguments, initialization, monitoring, simulation, and RTL schematic inspection. The available ALU RTL and TB are completed course templates with restricted-source headers, so this topic currently contains the brief only.

Course context: Maven Silicon, [Verilog lab manual - ModelSim and Quartus](https://elearn.maven-silicon.com/v3/myaccount/course/2383/lesson/2757?lesson=2757&section=275&class_id=17574&actualClassId=17574), printed pages 20–21. This is a short topic summary; the paid manual pages and supplied source files are not republished.
